# Changelog

Формат: [SemVer](https://semver.org/). Даты — по времени выхода сборки.

## 1.0.5

- **Поворот страниц** 90°/180°/270°: кнопки ↺/ в панели, горячие клавиши `R` / `Shift+R`,
  команды палитры «Повернуть страницы…».
- Поворот запоминается для каждого файла (вместе со страницей, масштабом и режимом).
- «По ширине» и «по окну» учитывают повёрнутые пропорции; позиция прокрутки при повороте сохраняется.
- Поворот выполняется CSS-трансформом отрисованного canvas — без повторного декодирования.
- Индикатор угла в статус-строке (`поворот 90°`).

## 1.0.4

- **Режим по умолчанию — «лента»**: файл открывается целиком как непрерывная прокрутка страниц.
- Миграция данных (`schemaVersion 2`): установки со старым дефолтом «постранично»
  однократно переводятся на ленту; ручной выбор пользователя больше не перезаписывается.
- Выбор режима по-прежнему запоминается отдельно для каждого файла (`M` / кнопка в панели).

## 1.0.3

- Исправлен watchdog: таймер зависания открытия больше не может быть погашен
  параллельным вызовом загрузки (симптом: вечный спиннер «Читаем…» без ошибки).
- Watchdog привязан к времени старта текущей загрузки и сам переставляется при конкурентных вызовах.
- Логи этапов открытия/рендера пишутся всегда (`console.info`, префикс `[DjVu Viewer]`),
  а не только при включённом отладочном логе.
- Таймаут декодирования одной страницы 60 с: вместо вечного «пульсирующего» плейсхолдера
  страница показывает блок ошибки с кнопкой «Повторить».
- Защита от шторма событий `modify` (перечитывание не чаще раза в 1,5 с) + лог самих событий.

## 1.0.2

- **Критический фикс**: `onLoadFile` не вызывал `super.onLoadFile(file)`, из-за чего `this.file`
  оставался `null` и открытие молча прерывалось после чтения файла (вечный спиннер,
  вкладка без имени, неработающие запоминание позиции и кэш).
- Страховка: `this.file` присваивается явно, если супер-реализация его не проставила.
- Все «тихие» ветки выхода из загрузки логируются и гасят watchdog.
- После открытия обновляется заголовок вкладки (имя файла).

## 1.0.1

- Watchdog открытия (60 с) с понятным экраном ошибки, списком причин и кнопкой «Повторить».
- Команда «DjVu Viewer: Диагностика…»: окружение, воркер, декодер, поиск конфликтующих
  djvu-плагинов, список открытых вкладок; отчёт дублируется в консоль.
- `new Worker()`/`URL.createObjectURL` обёрнуты в защиту от синхронного падения (CSP) —
  корректный переход на резервный режим в основном потоке.
- `INSTALL.txt` в архиве и раздел troubleshooting в README.

## 1.0.0

- Первый выпуск.
- Открытие `.djvu`/`.djv` кликом в проводнике, ribbon-кнопка, команды палитры,
  контекстное меню файла, drag&drop из ОС (с импортом в хранилище),
  URI `obsidian://djvu-viewer?vault=…&file=…&page=N`.
- Просмотр: постраничный режим и лента с предзагрузкой, масштаб 10–800 %,
  «по ширине»/«по окну», Ctrl+колесо, слайдер прогресса.
- Боковая панель: оглавление (закладки DjVu) и миниатюры с ленивым декодированием.
- Декодирование в фоновом Web Worker (Blob-URL, полностью офлайн, djvu.js 0.5.4)
  с автоматическим резервом на основной поток; жёсткая отмена через пересоздание воркера.
- LRU-кэш раскодированных страниц, запоминание позиции/масштаба/режима для каждого файла.
- Горячие клавиши просмотрщика и 16 команд; вкладка настроек; отладочный лог.
