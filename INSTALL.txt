УСТАНОВКА DjVu Viewer (Obsidian, только десктоп)
=================================================

1. Закройте Obsidian.

2. УДАЛИТЕ старые попытки установки, если они были:
     .obsidian/plugins/obsidian-djvu-viewer/      <- папка с ДРУГИМ именем = источник ENOENT
     .obsidian/plugins/djvu-viewer/               <- если ставили раньше
   и ОТКЛЮЧИТЕ/удалите любые прочие плагины для DjVu (они перехватывают расширение .djvu
   и могут «вечно крутиться» при открытии файла).

3. Распакуйте архив. Внутри — папка  djvu-viewer  с файлами:
       main.js  manifest.json  styles.css  icon.svg  versions.json  README.md
   ВАЖНО: имя папки должно остаться  djvu-viewer  (оно равно id плагина).

4. Скопируйте папку  djvu-viewer  в:
       <ваше хранилище>/.obsidian/plugins/
   Получится:  <хранилище>/.obsidian/plugins/djvu-viewer/main.js

5. Запустите Obsidian:
   Настройки -> Сторонние плагины -> выключить «Безопасный режим» (если включён)
   -> «Обновить список» -> включить «DjVu Viewer».

6. Положите любой .djvu в хранилище и кликните по нему.
   Горячие клавиши внутри просмотрщика: <-/-> страницы, +/-/0 масштаб, W по ширине,
   F по окну, M режим лента/постранично, T боковая панель.

ЕСЛИ ЧТО-ТО НЕ ТАК
------------------
* Ошибка «Plugin failure ... ENOENT ... main.js» — папка плагина названа не djvu-viewer
  или в ней нет main.js (см. шаги 2-4).
* Бесконечная загрузка файла — почти всегда конфликт с другим djvu-плагином (шаг 2).
* Самопроверка: Ctrl+P -> «DjVu Viewer: Диагностика: проверить воркер и декодер»,
  вывод придёт в консоль разработчика (Ctrl+Shift+I / View -> Toggle Developer Tools).
* Все мои сообщения в консоли начинаются с «[DjVu Viewer]».
